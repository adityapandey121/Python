# Vehicle Rental Management System

## Run
```powershell
python main.py
```

## Test
```powershell
python -m unittest discover -s tests -v
```

## Menu
1. Add Vehicle
2. Add Customer
3. Show Available Vehicles
4. Show Customers
5. Search Vehicles
6. Rent Vehicle
7. Make Payment
8. Return Vehicle & Print Invoice
9. Show Rental History
10. Exit

## Flow
Add vehicle/customer -> Rent vehicle -> Payment pending -> Make payment ->
Rental confirmed -> Return vehicle -> Late fee -> Invoice -> Vehicle available.

## OOP
The project demonstrates encapsulation, abstraction, inheritance,
method overriding, polymorphism, composition, and exception handling.
